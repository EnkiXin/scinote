# Frame-Selection Progress (SciVideoBench)

**Paradigm shift**: Stop putting the note into the answer prompt — instead use the note + question as a *signal* to pick which K frames the answer model sees.

```
full_video (32 frames)  →  selector(frames, note, question)  →  top-K frames
                        ↓
              Qwen-3B answers using ONLY video[top-K] + Q + options   (no note text)
```

Note source: the existing 3B-self-notes cache (`results_scivideobench/notes_cache`, generated by Qwen-3B with no Q/A leak).

## Setup

| Item | Value |
|---|---|
| Benchmark | SciVideoBench (n=1000, MCQ, 7 disciplines) |
| Candidate pool | 32 frames @ 1 fps |
| Selected K | 8 |
| Answer model | Qwen2.5-VL-3B-Instruct |
| Note model | Qwen2.5-VL-3B-Instruct (self-note, no Q/A) |
| CLIP model | openai/clip-vit-base-patch32 |

## Baselines

| Method | Acc (n) | Notes |
|---|---|---|
| C0 (paper Qwen-3B w/o note, full video) | **18.50%** | From SciVideoBench leaderboard |
| C-3B-self-note (note in answer prompt, full video) | 23.30% (n=1000) | Prior best with self-note |
| C-72B-oracle (note from 72B w/ answer, full video) | 48.60% (n=1000) | Upper bound, leaky |
| **Uniform K=8 (control)** | **19.23%** (n=962) | Naive uniform sampling 8/32 |

## 5 Frame-Selection Ideas

| # | Selector | Strategy | Acc | Δ vs Uniform |
|---|---|---|---|---|
| 1 | CLIP `score(frame, note+question) → top-K` | semantic alignment of note text with frame | **19.40%** (n=1000) | +0.17 |
| 2 | Entity `pick frames covering top entities in note` | extract quoted entities, max sim per frame | **17.00%** (n=1000) | −2.23 |
| 4 | Trajectory `parse timestamps/first/last cues` | inferred temporal window + dense sampling | **running** | — |
| 5 | Adaptive `equal-progress along ∑ ‖Δ frame embed‖` | sample dense where visual changes happen | **18.20%** (n=1000) | −1.03 |

**Idea 3** (Iterative refinement: re-write note from K_first → re-pick from K_second) was deprioritized as lowest expected value.

## TL;DR

**The "note-as-frame-selector" paradigm does NOT improve over uniform sampling.** All 4 completed selectors land within ±1pp of the Uniform K=8 control (19.23%), well within noise. The earlier C-3B-self-note result (23.30%) used **note text in the answer prompt** — that signal is more useful than reducing the frame budget.

Hypotheses for the negative result:
1. **Budget too small** — K=8 frames may be insufficient regardless of which 8; the answer model needs more context, not better frames.
2. **3B self-notes too generic** — without Q/A grounding, the note describes generic scene content, so CLIP/entity matching just rediscovers the same uniform frames.
3. **Visual diversity ≠ informativeness** — Adaptive's "where the picture changes" doesn't track *where the answer evidence lives*.
